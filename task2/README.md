# CodeAlpha Random Quote Generator

A simple and clean Random Quote Generator application built with Flutter as part of the CodeAlpha App Development Internship.

## 📱 Project Overview

QuoteFlow is a Random Quote Generator that displays inspirational quotes and their authors. Users can generate a new quote, save their favorite quotes, copy quotes to the clipboard, and switch between Light and Dark Mode.

## ✨ Features

* Display a random quote when the app opens
* Generate a new random quote
* Display quote author clearly
* Favorite quotes
* View saved favorite quotes
* Remove quotes from favorites
* Copy quote and author to clipboard
* Light Mode
* Dark Mode
* Save preferences locally
* Clean and user-friendly interface

## 🛠️ Technologies Used

* Flutter
* Dart
* Material Design
* SharedPreferences
* Flutter Clipboard API

## 🚀 How to Run

### Prerequisites

Make sure you have:

* Flutter SDK
* Dart SDK
* Android Studio or Visual Studio Code
* Android emulator or physical Android device

### Installation

Clone the repository:

```bash
git clone https://github.com/nouranagiy/CodeAlpha_RandomQuoteGenerator.git
```

Open the project:

```bash
cd CodeAlpha_RandomQuoteGenerator
```

Install dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run
```
